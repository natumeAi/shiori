# Routing

> `go_router` with typed routes generated by `go_router_builder`.
> Navigation always goes through a route class, never a string path.

---

## Files

- `lib/app/routes.dart`: every `@TypedGoRoute` class (+ `part 'routes.g.dart';`).
  The generator emits `$appRoutes` there.
- `lib/app/router.dart`: the `GoRouter` instance as a keep-alive provider
  (+ `part 'router.g.dart';`). Redirect logic (auth, onboarding) goes here.
- `lib/app/app.dart`: `MaterialApp.router(routerConfig: ref.watch(routerProvider))`.

Routes and the router provider are in separate files so riverpod_generator
and go_router_builder each own one `.g.dart`.

---

## Declaring Routes

```dart
// lib/app/routes.dart
part 'routes.g.dart';

@TypedGoRoute<BookmarkListRoute>(
  path: '/',
  routes: [TypedGoRoute<BookmarkDetailRoute>(path: 'bookmarks/:id')],
)
class BookmarkListRoute extends GoRouteData with $BookmarkListRoute {
  const BookmarkListRoute();

  @override
  Widget build(BuildContext context, GoRouterState state) =>
      const BookmarkListScreen();
}

class BookmarkDetailRoute extends GoRouteData with $BookmarkDetailRoute {
  const BookmarkDetailRoute({required this.id});

  final String id;

  @override
  Widget build(BuildContext context, GoRouterState state) =>
      BookmarkDetailScreen(id: id);
}
```

```dart
// lib/app/router.dart
part 'router.g.dart';

@Riverpod(keepAlive: true)
GoRouter router(Ref ref) {
  final router = GoRouter(routes: $appRoutes);
  ref.onDispose(router.dispose);
  return router;
}
```

`go_router` is held at 17.x; see the version pins in
[Quality Guidelines](./quality-guidelines.md).

Conventions:

- Route class name = screen name with `Route` instead of `Screen`
  (`BookmarkDetailScreen` <-> `BookmarkDetailRoute`).
- Path segments are lowercase, plural nouns: `/bookmarks/:id`, `/settings`.
- Path/query parameters are constructor fields (`String`, `int`, enums).
  Pass ids, not whole objects. The target screen loads data by id.
- Screens receive route parameters through their constructor; they never
  read `GoRouterState` themselves.

## Navigating

```dart
const BookmarkDetailRoute(id: 'abc').go(context);    // replace stack per route tree
BookmarkDetailRoute(id: bookmark.id).push(context);  // push on top
context.pop();                                       // go back
```

Dialogs and bottom sheets are not routes: use `showDialog` /
`showModalBottomSheet` directly.

---

## Forbidden

- String navigation: `context.go('/bookmarks/$id')`, `context.push('/settings')`.
- `Navigator.push(MaterialPageRoute(...))` for full pages.
- Creating a `GoRouter` outside `routerProvider` (a router created in `build`
  resets navigation state on every rebuild).
- Navigating from inside a provider or repository. Navigation is a UI concern:
  react with `ref.listen` in the widget, or redirect in `router.dart`.
