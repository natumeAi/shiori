# Directory Structure

> Feature-first layout: each feature owns its data and presentation code;
> app-wide wiring lives in `app/`, shared building blocks in `core/`.

---

## Layout

```text
lib/
  main.dart                      # bootstrap only: logging, ProviderScope, runApp
  main_probe.dart                # explicit synthetic/reader diagnostics entry point
  app/
    app.dart                     # ShioriApp (MaterialApp.router)
    probe_app.dart               # isolated probe shell, no normal route changes
    routes.dart                  # typed route classes (+ routes.g.dart)
    router.dart                  # routerProvider (+ router.g.dart)
    theme.dart                   # AppTheme.light / AppTheme.dark
  core/
    config/env.dart              # compile-time config (--dart-define)
    diagnostics/                 # storage-free bounded recorder, models, summary
    storage/                     # injectable Application Support/Documents resolver
    errors/app_exception.dart    # sealed AppException hierarchy
    errors/error_messages.dart   # AppException -> localized message
    logging/logging.dart         # setupLogging()
    network/dio_provider.dart    # configured Dio + dioProvider
    network/guard_dio.dart       # DioException -> AppException
    network/retry_policy.dart    # Riverpod retry policy
    widgets/                     # widgets shared by 2+ features (ErrorView, ...)
  features/
    reader/                      # reusable core; see reader-engine.md
      data/
        epub/                    # ZIP/package/spine/TOC and resource rewriting
        source/                  # parsing, inert projection, source positions/work guard
        cfi/                     # Foliate-compatible grammar, export and resolution
        canonical/               # normalization v1, generated Unicode ranges, FNV-1a64
      engine/
        style/                   # CSS subset, cascade, reader overrides (pure Dart)
        layout/                  # blocks, paragraphs, fonts, images and SVG
        pagination/              # preparation, page plans/maps, conservation and anchors
        support/                 # unsupported-layout detection
        motion/                  # numeric gesture/turn controller, clocks and sink seams
        surface/                 # retained pictures/leases and PreparedReader widget
    diagnostics/
      data/                      # local books, preparation owner, recorder, export/channel adapters
      presentation/
        reader_probe/            # probe controls, scenario runner and frame-driven injection
    <feature>/                   # plural noun, snake_case: bookmarks, settings
      data/
        models/<model>.dart      # freezed models (+ .freezed.dart / .g.dart)
        <feature>_repository.dart
      presentation/
        <name>_screen.dart       # route target widget
        <name>_controller.dart   # AsyncNotifier backing the screen (optional)
        widgets/                 # widgets private to this feature
  l10n/
    app_zh.arb                   # template ARB (source of truth)
    app_<locale>.arb             # other locales
    app_localizations*.dart      # generated by gen-l10n, do not edit
    l10n.dart                    # context.l10n extension + export
test/                            # mirrors lib/ (see testing.md)
  fixtures/reader/
    oracle/                      # authoritative synthetic WebKit vectors + Unicode table
    source_edge/                 # two synthetic edge EPUBs, vectors and hashed manifest
    exports/                     # deterministic synthetic analyzer exports
assets/reader_fixtures/           # bundled synthetic EPUBs + hashed manifest only
tool/
  oracle/                        # Node/Playwright oracle, synthetic sources, reference copies
  reader/                        # Unicode generation, native CFI interop and source_edge builder
  diag/                          # independent pure Dart reader export analyzer
  ci/                            # fixture/privacy guard and unsigned iOS packaging
ios/Runner/AppDelegate.swift      # diagnostic presentation channel/native sampling
.trellis/tasks/<task>/evidence/   # reviewable command records; no private book payloads
build/oracle-local/               # gitignored private vectors/resolve results; may contain book text
local-evidence/                   # gitignored raw personal/device exports
config/                          # --dart-define-from-file JSON (dev.json placeholders; local.json git-ignored)
```

`app/`, `core/`, and `l10n/` exist as shown. `features/home/presentation/home_screen.dart`
is a placeholder routed at `/` (no data layer); the first real feature
replaces or extends it.

## Where Does New Code Go?

| You are adding... | Put it in |
|---|---|
| A new screen | `features/<feature>/presentation/<name>_screen.dart` + a route in `app/routes.dart` |
| State for a screen | `features/<feature>/presentation/<name>_controller.dart` |
| A widget used by one feature | `features/<feature>/presentation/widgets/` |
| A widget used by 2+ features | `core/widgets/` |
| An API model | `features/<feature>/data/models/` |
| API calls | `features/<feature>/data/<feature>_repository.dart` |
| A model shared by 2+ features | keep it in the owning feature's `data/models/`; other features import it from there |
| UI text | `l10n/app_zh.arb` (and other locales) |
| Colors, typography | `app/theme.dart` |
| Reusable timing samples/records and aggregation | `core/diagnostics/` (no feature or storage imports) |
| Platform app-directory resolution | `core/storage/` (no marker/export formats) |
| Probe marker, saved record and export files | `features/diagnostics/data/` |
| Synthetic capture animation and declaration form | `features/diagnostics/presentation/` |
| EPUB/source/CFI/canonical operations | `features/reader/data/` (pure Dart) |
| Reader style/layout/pagination/motion and resource ownership | `features/reader/engine/` |
| Reader probe scenarios and capture controls | `features/diagnostics/presentation/reader_probe/` |
| Offline reference extraction / native interop / export analysis | `tool/oracle/` / `tool/reader/` / `tool/diag/` |

## Import Boundaries

- `features/<a>/**` may import `core/**`, `l10n/**`, and `features/<b>/data/**`.
- `features/<a>/**` must **not** import `features/<b>/presentation/**`.
- Reader-core exception: diagnostics may import `features/reader/engine/**`
  as well as its data layer. The reader core must never import diagnostics.
  Engine-owned injected sink interfaces keep that dependency one-way.
- `reader/data/**` has no `dart:ui`, Flutter or provider imports. The engine
  may use `dart:ui`; widgets belong only in `reader/engine/surface/`. Neither
  reader layer declares providers. See [Reader Engine](./reader-engine.md).
- `core/**` must not import `features/**` or `app/**`.
- `app/**` may import anything (the router needs every screen).
- Always use package imports: `import 'package:shiori/core/errors/app_exception.dart';`,
  never relative `../` imports.

## Naming

- Files and directories: `snake_case`. One public top-level class per file,
  named after the file (`bookmark_list_screen.dart` -> `BookmarkListScreen`).
  Private helper widgets may share the file.
- Suffixes: `*Screen` (route target), `*Controller` (Notifier/AsyncNotifier),
  `*Repository`, `*Route` (typed route), `*Exception`.
- Generated files (`*.g.dart`, `*.freezed.dart`, `app_localizations*.dart`)
  sit next to their source and are committed. Never edit them by hand.
  The canonical Unicode table is generated by `tool/reader/generate_unicode_table.dart`,
  not by build_runner.

## Fixture and Evidence Boundaries

`tool/oracle/fixtures/<id>/` contains hand-authored synthetic sources;
`tool/oracle/reference/lan-reader-a4bda23/` contains attributed pinned source.
`assets/reader_fixtures/manifest.json` and
`test/fixtures/reader/source_edge/manifest.json` identify allowed EPUB payloads
by byte count and SHA-256. Do not add a user book to any fixture directory.
Full Chromium cross-check vectors live in ignored `build/oracle-chromium/`;
only WebKit vectors, summary and differences are committed.

For S2, task command records are indexed in
`.trellis/tasks/10-22-native-reader-feasibility/evidence/README.md`. Keep raw
personal captures in `local-evidence/` and real-book vectors in
`build/oracle-local/`; a task evidence folder is not a privacy exemption.
Both private locations are gitignored. Fixture guards and product asset
carry-forward are specified in [Quality Guidelines](./quality-guidelines.md).

## Common Mistakes

- Putting a feature's widget in `core/widgets/` "in case" it gets reused.
  Move it to `core/` when the second feature actually needs it.
- Adding layer-first folders (`lib/models/`, `lib/screens/`). Everything
  feature-specific lives under `features/<feature>/`.
- Putting app setup (router, theme, ProviderScope config) in `main.dart`.
  `main.dart` only calls `setupLogging()` and `runApp`.
